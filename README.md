# 🚑 SOS First Aid Assistant (المساعد الإسعافي)

A modern, responsive web application designed to provide immediate first aid guidance and emergency support. This tool is built to help users respond quickly and effectively to common life-threatening situations.

## 🌟 Features

- **Drowning Rescue (انقاذ الغريق)**: Step-by-step guidance on how to save someone from drowning.
- **Choking (الاختناق)**: Critical actions to take when someone is choking.
- **Fire Safety (الحريق)**: Essential protocols for responding to fire emergencies.
- **CPR (الانعاش الرئوي)**: Clear instructions and video tutorials for performing Cardiopulmonary Resuscitation.
- **Fall Incidents (حالات سقوط)**: How to handle injuries resulting from falls.
- **Emergency Shortcut (انقلني الى الطوارئ)**: Quick access to emergency services.
- **Vital Information (المعلومات الحيوية)**: Tracking and viewing essential health data.

## 🚀 Tech Stack

- **Frontend**: HTML5, Vanilla CSS3
- **Bundler**: [Parcel](https://parceljs.org/)
- **Design**: Responsive layout with modern typography (Inter) and interactive components.

## 🛠️ Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (v14 or higher recommended)

### Installation & Running

1. **Clone or Download** the project to your local machine.
2. Open your terminal in the project directory.
3. Install dependencies:
   ```bash
   npm install
   ```
4. Start the development server:
   ```bash
   npm start
   ```
5. Open your browser and navigate to `http://localhost:1234` (or the port displayed in the terminal).

## 📁 Project Structure

- `index.html`: Main entry point and application structure.
- `index.css`: Core styling and layout definitions.
- `global.css`: Global styles and CSS variables.
- `public/`: Directory for assets like images and logos.
- `AccountSystem.vdmsl`: Formal specification for the account management system (VDM-SL).
